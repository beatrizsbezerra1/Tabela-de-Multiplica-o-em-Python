# Tabela-de-Multiplica-o-em-Python# Tabela de Multiplicação em Python (`multiplication-table-python`)

Um programa simples de linha de comando desenvolvido em **Python 3** que recebe um número inteiro e exibe a sua tabela de multiplicação (tabuada) do `1` ao `10`.

---

## 📋 Sobre o Projeto

A finalidade deste programa é calcular e imprimir os dez primeiros múltiplos de um número inteiro informado pelo usuário. Ele foi desenvolvido utilizando apenas recursos nativos do Python, sem a necessidade de instalar bibliotecas ou pacotes externos.

### 📂 Estrutura de Arquivos

* `main.py` — Código-fonte principal do programa.
* `LICENSE` — Licença MIT do projeto (Copyright © 2026 Neps Academy).
* `README.md` — Documentação e instruções de uso do projeto.

---

## ⚙️ Pré-requisitos e Instalação

Para executar este programa, você precisa ter instalado em seu computador:

1. **Python 3** (disponível em [python.org/downloads](https://www.python.org/downloads/)).
2. *(Opcional)* **Visual Studio Code** com a extensão oficial **Python** da Microsoft, caso prefira rodar o código por um editor.

Não há dependências externas para instalar via `pip`.
